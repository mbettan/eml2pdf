The Challenge

Email archival is
fundamentally complex.

Legacy rendering engines break modern responsive email layouts, fail to handle offline inline assets cleanly, execute remote tracking hits that leak private data, or crash completely when nested tables generate endless paged height calculation loops. Eml2pdf fixes all of this.

The Old Way

Fragile Rendering Engines

WKHTMLtoPDF and ad-hoc script workflows crash, leak security coordinates, and drop critical attachment data during conversions.

  • External image fetching leaks client analytics to remote tracking pixels
  • Nested percentage table structures lock WeasyPrint into endless layout loops
  • Local CID inline image paths break, resulting in empty visual frames
  • Essential attachment information is completely lost in the PDF
The eml2pdf Way

Robust Archival Architecture

Standards-compliant HTML/CSS compilation, sandboxed HTTP routing, and custom layout overrides ensure absolute structural preservation.

  • Strict URL sandboxing isolates external tracking Hits by default
  • Dynamic layout CSS overrides neutralize height loop hang hazards
  • MIME CID parts are parsed and integrated directly as Base64 data
  • Elegant attachment footer manifest with custom MD5 Checksums
Engine Capabilities

High-fidelity conversions
with multi-core speed.

Parallel Batch Ingestion

Leverage a high-performance multi-core worker Pool using Python's native `multiprocessing` to recursively walk and convert directories containing thousands of EML files in seconds.

# Setup parallel batch converter pipeline
from eml2pdf import EmailToPDFConverter
converter = EmailToPDFConverter(page_size="a4", add_attachment_names=True)
stats = await converter.convert_directory("./eml", "./pdf", num_procs=4)

Inline CID Embedding

Automatically identifies local inline images nested within EML MIME boundaries, resolving their paths and compiling them directly as Base64 data URIs for offline portability.

Strict HTML Sanitization

The parser decomposes script blocks, iframe boundaries, plugin resources, and all `on*` event properties, keeping the compiled PDF immune to XSS injections.

Markdown Prose Fallback

Plaintext emails are processed through standard Markdown compilation layers, translating unstyled paragraphs into clean typographic headers and bullet points.

Layout Loop Overrides

Injects targeted layout overrides that reset nested table heights and float variables, preventing infinite height calculations and WeasyPrint engine hangs.

Ingestion Loop

How the conversion works.

A secure, automated ingestion pipeline designed for perfect local execution.

Step 01
Ingest EML

Reads the raw file and maps metadata (From, To, Date) to a standardized structured model.

Step 02
Sanitize HTML

Neutralizes scripts, strips tracking pixels, and bundles CID inline attachments into Base64.

Step 03
Apply CSS overrides

Injects height and reset variables to bypass layout-looping WeasyPrint hangs.

Step 04
PDF Compilation

Renders a highly portable vector PDF equipped with a cryptographic MD5 attachment manifest footer.
