The Challenge

Email Archiving is
frequently broken.

Legacy renderers break CSS layouts, fail to load offline inline assets, execute remote tracking requests that leak private data, or hang forever on nested percentage tables. Eml2pdf fixes all of this.

The Old Way

Fragile Rendering Engines

WKHTMLtoPDF and other tools break layouts, leak security, and fail on modern responsive newsletter code templates.

  • External image loads leak privacy data to remote trackers
  • Nested table heights trigger endless page rendering hangs
  • CID inline images break, producing empty resource frames
  • Attachment details are completely lost in the PDF
The eml2pdf Way

Robust Archival Architecture

WeasyPrint backend rendering combined with strict security filters and smart layouts guarantee reliable outputs.

  • Strict URL sandboxing isolates external tracking hits by default
  • Dynamic layout rules override and neutralize WeasyPrint height loops
  • MIME CID parts are decoded and integrated directly as Base64
  • Elegant footer attachment listings with custom MD5 Checksums
Core Features

Engineered for absolute accuracy
and enterprise speed.

High-Performance Library API

Leverage a multi-core worker Pool using Python's native multiprocessing to convert directories containing thousands of EML files in seconds.

# Setup parallel batch converter pipeline
from eml2pdf import EmailToPDFConverter
converter = EmailToPDFConverter(page_size="a4", add_attachment_names=True)
stats = await converter.convert_directory("./eml", "./pdf", num_procs=4)

Inline CID Asset Ingestion

Automatically extracts local inline images embedded inside MIME layers and re-injects them as compiled base64 data URIs.

Security Sanitization

Strips out script blocks, iframe sources, flash plugins, and on* DOM events to secure archived views.

Markdown Plaintext Fallback

No HTML part? Plaintext bodies are parsed through Markdown compiler layers for a premium typography layout.

Layout Infinite-Loop Overrides

Detects and breaks layout looping hazards caused by nested percentage elements, ensuring WeasyPrint never hangs.

Archival Pipeline

Safe Conversion Workflow

A reliable conversion loop that safeguards privacy and produces clean documents.

Step 01
EML Ingestion

Raw MIME structures are decoded, extracting HTML/plain text and attachment elements.

Step 02
MIME Sanitization

Harmful JS tags are removed, and CID images are embedded as Base64.

Step 03
Sandboxed Compilation

The WeasyPrint engine renders the layout in a sandboxed loop, blocking tracking hits.

Step 04
PDF Archive

A vector PDF is produced with a detailed header and attachment metadata footer.
