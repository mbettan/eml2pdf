Quick Start & System Requirements

eml2pdf relies on WeasyPrint for PDF compilation. To guarantee premium typography, font layouts, and vector output, install the following system libraries:

macOS (Homebrew) 
brew install cairo pango gdk-pixbuf libffi
Linux (Ubuntu/Debian) 
sudo apt-get install libcairo2 libpango-1.0-0 libgdk-pixbuf2.0-0 libffi-dev shared-mime-info
Python Installation 
pip install eml2pdf
# Or manually from source:
pip install -r requirements.txt
03

CLI Subcommands & Options

The modern interface splits operations into subcommands to handle single conversions or heavy parallel batch operations cleanly.

Convert Single EML 
python eml2pdf.py convert_file email.eml output.pdf
Batch Directory Conversion 
python eml2pdf.py convert_dir ./emails/ ./pdfs/ --smart-naming -n 4

Shared Rendering Options

  • -p, --page SIZE — Page dimensions like "a4", "letter", or "letter landscape"
  • -hh, --hide-headers — Suppresses the structured email header box block
  • -a, --extract-attachments — Automatically extracts attachments to dedicated folders
  • -aa, --add-attachment-names — Generates an attachment overview table at the footer with **MD5 Checksums**
  • --unsafe — Disables HTML sanitization and allows external remote image resolution
  • --skip-ssl-verification — Bypasses SSL certificate validation for legacy remote trackers/servers
04

Python Library Integration API

Use eml2pdf directly within your internal applications or custom data ingestion lines.

Python 
from eml2pdf import EmailToPDFConverter

# Configure a premium converter
converter = EmailToPDFConverter(
    page_size="letter landscape",
    dpi=300,
    add_attachment_names=True,
    extract_attachments=True
)

# Convert a single EML
converter.convert("newsletter.eml", "newsletter.pdf")

# Execute a high-performance parallel batch conversion
stats = converter.convert_directory(
    input_dir="./archive/eml",
    output_dir="./archive/pdf",
    num_procs=4,
    smart_naming=True
)
print(f"Successfully archived {stats['success']} emails.")

06

Technical Architecture Bento

Base64 CID Embedding

Resolves local cid: inline attachments from MIME structures and embeds them directly as highly compressed inline Base64 images, guaranteeing 100% offline portability of the PDF without broken resource blocks.

Parallel Processing

Spins up a multi-core `multiprocessing` Pool to slice and convert folders containing thousands of EML files simultaneously.

Sortable Naming

Uses a deterministic {YYYY-MM-DD}-{subject}.pdf smart-naming pattern with filesystem character-sanitization and collision-safeguards.

Layout Hang Fixes

Injects CSS properties to dynamically override infinite layout loops caused by nested percentage height alignments, preventing WeasyPrint hangs.

Markdown Fallback

When emails have no HTML part, the engine dynamically renders the plain-text body using Markdown conversion rules for clean visual structure.
